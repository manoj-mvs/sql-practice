# SQL Practice Repository

A collection of SQL practice questions and solutions from platforms like LeetCode, HackerRank, DataLemur, and more. This repository focuses on SQL problem-solving, query optimization, interview preparation, and real-world query patterns.

- Joins
- Window Functions
- CTEs
- Subqueries
- Aggregations
- Ranking Functions
- Date & String Functions
- Query Optimization
